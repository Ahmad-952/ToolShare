ToolShare - Visual Programming (CS-284) Assignment 2
Blazor Server (.NET 8) + EF Core + SQL Server LocalDB

How to run:
1. Open ToolShare.csproj in Visual Studio 2022
2. Press F5 (or run: dotnet run, then open http://localhost:5080)
3. Database ToolShareDb is created automatically on first run.

Use the "Ali (owner)" / "Sara (borrower)" buttons in the top bar to switch users.
